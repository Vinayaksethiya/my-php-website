# BehiveAds LeadGen - PHP WordPress Theme

A WordPress lead-generation theme for **BehiveAds** (behiveads.com) with 7 landing pages.

## Pages
- Pest Control
- Auto Insurance
- Health Insurance
- Medicare
- Home Services
- Final Expense
- Water Services

## Tech Stack
- WordPress + PHP 8.2
- MySQL 8.0
- Apache
- Docker / XAMPP

## Run with Docker
```bash
docker compose up --build
```
Open: http://localhost:8080

## Run with XAMPP
Copy theme to `C:\xampp\htdocs\myproject\wordpress\wp-content\themes\`
